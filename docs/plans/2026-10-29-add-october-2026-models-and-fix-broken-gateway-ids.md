# Add October 2026 models and fix broken gateway ids

## Context

The Vercel AI Gateway changed under us: `xai/grok-imagine-video-1.5-preview` now returns 404 (Grok video is broken in prod), `perplexity/sonar-pro` and `perplexity/sonar-reasoning-pro` are silently served as plain Sonar, and xAI moved to the `spacexai/*` namespace (old `xai/*` ids are only aliases). At the same time 12 new chat models, 4 new image models and 1 new video model with known prices appeared. Goal: fix the broken/misleading entries, add the priced models to the picker, and give every new model a Russian SEO landing.

Decisions taken with the user:
- Data source: the user's table (ids, prices, dates). `ai-gateway.vercel.sh` and `vercel.com` are blocked in this sandbox; research agents cross-check through WebSearch (it indexes `vercel.com/ai-gateway/models/*`). The user re-checks with `pnpm models:list` before merge.
- Models without a gateway price (FLUX 3 Klein, Recraft v4.1 Flash, Grok Video 1.5 Lite, Wan v3.0 Prime, MiniMax H3 Max, Veo 3.1 Lite, Seedance 2.0 Mini, Kling v3.0 Motion Control) are **skipped**: media is billed from gateway `cost`, so $0 means free generation.
- Sonar Pro / Sonar Reasoning Pro: **hidden** (`showInUI: false`), landings + catalog cards removed, 301 redirects to `/models/perplexity-sonar`.
- Qwen 3.7 Flash **stays**, Qwen 3.8 Flash added next to it (3.7 marked previous generation).
- Image landings: first drafted in a doc with render prompts (renders were not possible in the cloud sandbox), then wired in this PR in a follow-up local pass with real renders generated by each model through the gateway (Nano Banana 2.1, Flux 3 Image, MAI-Image 2.6, MAI-Image 2.6 Flash); landings, catalog cards and cross-links are live and the draft doc is deleted.

## Order of work (multi-agent workflow)

Orchestrator: Opus (main loop). Coders: Sonnet. Research, content/SEO, review: Opus.

1. **Verify** (Opus ×2, parallel) — WebSearch each id on `vercel.com/ai-gateway/models/*` and vendor pages: gateway type (language/image/video), price, context, vision/PDF/reasoning/tools, video params. Output a facts table; unknowns marked `unverified`.
2. **Build** (parallel)
   - Registry coder (Sonnet) — all code wiring above. Unverified capability → conservative default (no attachments, no thinking picker, no media settings that might be placebo).
   - Content writers (Opus ×3: OpenAI/Google/Moonshot/Alibaba/DeepSeek; Meta/Mistral/Z.ai/MiniMax/Xiaomi; media) — Russian landing copy + catalog card as JSON in the scratchpad, matching `lib/marketing/model-landings/types.ts`; claims only from the facts table.
3. **Landings** (Sonnet) — turn JSON into landing modules, slugs, catalog cards, Sonar removal + redirects, image draft doc.
4. **Review** (Opus ×2, parallel) — code/billing/conventions review (repo `review` agent) and content/SEO review.
5. **Fix** (Sonnet) — apply confirmed findings, run full `pnpm check`.
6. Orchestrator re-runs `pnpm check`, reads the diff, commits, pushes to `claude/eager-carson-nk9euo`.
7. **Local follow-up** (Opus manager + executors + reviewers, with a live `AI_GATEWAY_API_KEY`): check every id against the live catalog, smoke-test the runtime with minimal paid calls, generate the image renders and wire the image landings, fix billing/routing issues the probes exposed, full `pnpm check` incl. `next build`.

## Risks

- **Live gateway check done** (2026-10-29, `/v1/models` + paid probes): every new id exists, DeepSeek V4.1 Flash 1017 is $0.075/$0.30 per 1M (with x2 peak-pricing windows), `spacexai/grok-4.3` and `grok-4.6` exist.
- **Text billing now bills the gateway cost first.** Probes showed TokenLens (models.dev) mis-prices several new models (2x on mistral-large-4 and deepseek-v4.1-flash-1017, ~0.57x on glm-5.3, cache reads at the full input rate on minimax/grok). `mergeUsage` bills the sum of the steps' `providerMetadata.gateway.cost` when reported and falls back to TokenLens otherwise. Text turns are charged whenever the merged total is > 0; a missing TokenLens catalog no longer zeroes the charge. Still check the first prod `Transaction` per model.
- **Sonar Pro / Sonar Reasoning Pro left the gateway catalog.** The gateway still redirects them to `perplexity/sonar`; `providers.ts` now aliases both hidden ids to `perplexity/sonar` itself (no `<think>` wrapper), so old chats keep working and are priced at Sonar's rate.
- **Grok video** under `spacexai/` reads resolution from the `xai` namespace only (480p → 848x480 at $0.08/s, 720p → 1280x720 at $0.14/s). Text-to-video works on the stable id (prompt-only clip returned 1280x720 with audio), so `imageInput: "optional"` stays.
- **Wan video length capped at 5 s** (departure from the original 5/10/15/30 and from the cloud PR's 5/10): with no resolution the gateway renders 1080p at $0.20/s and a 5 s clip took 130 s; a 10 s clip risks the 300 s route limit before `chargeUsageSafe` runs. Add 10 s+ only after timing it on prod or pinning a lower tier (uppercase `"720P"` token unverified). Landing copy promises 5 s clips only.
- MiniMax M3.1 Flash streams native reasoning (no `<think>` tags); the middleware wrapper stays as a no-op guard. Meta Muse keeps reasoning hidden. Mistral, Z.ai and Xiaomi stream native reasoning parts.
- Nano Banana 2.1 streams two image files (a 1376x768 preview, then the final); the app keeps the last one. `imageSize` is honoured (2K → 2752x1536, 4K → 5504x3072). Any code path taking `result.files[0]` would deliver the preview.
- MAI-Image 2.6 / Flash single-image edits work through `gateway.imageModel` although the catalog lists text-only input; edit output is 1024x1024 (only a square input was tested).
- Known minor: the dedicated image provider labels Grok images `image/png` while the gateway returns JPEG.
